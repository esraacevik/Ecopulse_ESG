# ECOLOGIA Frontend

Distinctive, production-grade frontend for ESG Carbon Calculator

## Design Philosophy

- **Aesthetic**: Refined minimalism with organic/natural elements
- **Typography**: Playfair Display (display) + Inter (body)
- **Color Palette**: Forest green (#2E7D32) + Sage tones
- **Motion**: Framer Motion for smooth animations
- **Layout**: Asymmetric, grid-breaking elements with generous spacing

## Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Features

- Emission calculation form
- Real-time results display
- Scope breakdown visualization
- Data source indicators
- Responsive design
- Smooth animations

## API Integration

Frontend connects to backend API at `http://localhost:8000` (configurable via `NEXT_PUBLIC_API_URL`)
